# 🤖 AI Chatbot using NLP

## 📌 Description
This project is a simple AI chatbot that understands user queries and responds intelligently using Natural Language Processing and Machine Learning techniques.

The chatbot classifies user input into different intents and generates varied responses, making the interaction more natural.

---

## 🚀 Features
- Intent classification using Logistic Regression
- TF-IDF based text vectorization
- Dynamic response generation (varied replies)
- Confidence-based fallback mechanism
- Simple and interactive chatbot UI (Streamlit)

---

## 🛠️ Tech Stack
- Python
- NLTK
- Scikit-learn
- Streamlit

---

## ▶️ How to Run

### 1. Install dependencies

pip install -r requirements.txt

## Train the model
python train.py

## Run chatbot (in terminal)
python app.py

## Run chatbot (UI)
streamlit run ui.py
